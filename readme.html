待办事项应用 - 工作模式说明

本地开发模式 完整功能

在本地开发环境中，应用提供完整的待办事项功能：

  • 添加、删除和修改待办事项
  • 标记待办事项为已完成或未完成
  • 过滤显示全部、已完成或未完成的待办事项
  • 使用浏览器的 localStorage 保存数据

这使您可以在开发过程中测试所有功能。

GitHub Pages 模式 只读展示

在 GitHub Pages 上部署时，应用将以只读模式运行：

  • 显示预设的待办事项列表
  • 允许查看和过滤待办事项
  • 禁用添加、删除和修改功能
  • 不使用 localStorage 存储数据

这种模式适合作为展示用途，让访问者了解应用的界面和基本功能，而无需担心数据存储问题。
